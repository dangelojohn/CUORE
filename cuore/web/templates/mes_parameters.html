How to capture a module in MultiEcuScan

  1. Close CUORE's live board and sensor check (only one program can use the adapter). Key on; engine running if you want running values.
  2. In MES pick the module and fit the cable the list below names, then Connect.
  3. Open the Parameters tab and add every parameter the module offers to the list MES is reading.
  4. Leave it reading for about 30 seconds, then disconnect. MES saves the values in its session log.
  5. Reload this page: the module turns to "captured" and its full list appears.

Read-only: this never clears codes or runs tests. CUORE reads the MES log files on this PC; it does not talk to the car here.
