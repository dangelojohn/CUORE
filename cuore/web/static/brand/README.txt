Brand files for the header badge slot (.logo-slot in cuore.css), the intro
overlay (_intro.html) and the mobile header (m_base.html).

alfa-romeo-logo.png  512x512 RGBA, the current Alfa Romeo badge. Supplied by
    the project owner on 2026-10-29 (file "Alfa-Romeo-Logo.png" from the
    owner's desktop, SHA-1 9e1bfd036ba2788da2c0a5055103005e62cb9878). The
    owner reported the same day that Stellantis / Alfa Romeo granted CUORE
    permission to use the Alfa logos, fonts and graphics and asked for the
    badge in the UI (docs/project/CORPORATE_ACCEPTANCE_2026-10-29.md). The
    badge is a Stellantis trademark: it identifies the marque the page is
    themed for and is used nowhere else.

logo.svg  (not present) CUORE's own mark. Until it exists, a marque without
    a badge file shows the dashed "LOGO" stand-in in the header slot and the
    intro overlay shows the CUORE wordmark alone.

maserati-trident.svg  Wikimedia Commons "File:Maserati_logo_2.svg", fetched
    2026-10-29 with the owner's approval (SHA-1 7273968493ea8...). Commons tags:
    public domain (simple shapes, below the threshold of originality) and
    "may be protected as a trademark"; single-colour black, no wordmark. Used as
    a CSS mask in the ink colour for data-marque="maserati" (header, intro,
    mobile). The owner reports the marque's agreement; keep the written
    permission with the brand package when it arrives.

ferrari-wordmark.svg  Wikimedia Commons "File:Ferrari_wordmark.svg", fetched
    2026-10-29 with the owner's approval (SHA-1 3f24e8cc68062...). Tags: public
    domain, trademarked. The prancing-horse shield is copyrighted artwork that
    Commons does not host; it must come from Ferrari with permission, and then
    replaces the wordmark in the same slot (data-marque="ferrari").

ferrari-horse.svg  Demo only, git-ignored, never in the public repo. Vector horse
    from ferrari.com (the site header logo, in its site script) on 2026-10-31 at the
    owner's request (rights expected, not yet in writing). When present it
    replaces the wordmark; without it the wordmark shows.
