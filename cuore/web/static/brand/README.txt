Brand files for the header badge slot (.logo-slot in cuore.css), the intro
overlay (_intro.html) and the mobile header (m_base.html).

alfa-romeo-logo.png  512x512 RGBA, the current Alfa Romeo badge. Supplied by
    the project owner on 2026-10-29 (file "Alfa-Romeo-Logo.png" from the
    owner's desktop, SHA-1 9e1bfd036ba2788da2c0a5055103005e62cb9878). The
    owner reported the same day that Stellantis / Alfa Romeo granted CUORE
    permission to use the Alfa logos, fonts and graphics and asked for the
    badge in the UI (docs/project/CORPORATE_ACCEPTANCE_2026-10-29.md). The
    badge is a Stellantis trademark: it identifies the marque the page is
    themed for and is used nowhere else.

logo.svg  (not present) CUORE's own mark. Until it exists, a marque without
    a badge file shows the dashed "LOGO" stand-in in the header slot and the
    intro overlay shows the CUORE wordmark alone.

Maserati and Ferrari badges: add <marque>-logo.png here and a matching
:root[data-marque="<marque>"] .logo-slot rule in cuore.css, once their
permission is on file.
