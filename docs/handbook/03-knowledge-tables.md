# Knowledge tables

All tables below live in `mes-log-mcp/mes/`. They are 2018 Alfa Romeo Stelvio 2.0T (US/GU) data unless noted. Entry counts are `len()` of the module's main constant, run on 2026-10-07 -- re-run the same call if the data has grown. "Known gaps" is a grep count of the literal string `UNKNOWN` in the file (an undercount of real gaps where a module uses a different sentinel, noted per row).

Shared confidence vocabulary (most modules): `CONFIRMED` (manufacturer document), `CORROBORATED` (two independent non-manufacturer sources agree), `SINGLE_SOURCE` (one source, not cross-checked), `UNKNOWN` (nothing credible found -- the value is `None`, never a guessed placeholder, and `notes` points at the service manual/TechAuthority). `mes.electrical` and `mes.layout_systems` add `INFERRED` (reasoned from sourced facts, with the reasoning stated).

## State-backed records (not sourced reference data -- attested, append-only)

These are driver/mechanic/dealer input, kept in `CUORE_STATE_DIR` as JSONL, and explicitly never treated as car measurements or entered into the evidence gate as such (see `docs/handbook/README.md`'s conventions line and `02-architecture.md`'s state directory table for exact file paths).

| Kind | Module | Notes |
|---|---|---|
| Notes | `mes-log-mcp/mes/notes.py` | Append-only; `edit_note` appends an amendment, `hide_note` appends a hide record -- history is never rewritten |
| Symptoms | `mes-log-mcp/mes/symptoms.py` | What a person felt, distinct from what the car measured; `hide_symptom` never rewrites history either |
| Feedback | `mes-log-mcp/mes/feedback.py` | Correction/question/confirmation/input/disagreement pinned to one page/section/item cuore showed; status flows open -> answered/applied/dismissed |
| Jobs | `mes-log-mcp/mes/jobs.py` | One Job per shop visit: complaint, hypotheses (each with real evidence for/against), actions, verification -- ties the other stores together per visit |
| Media | `cuore/live/media.py` | Evidence photos/scans/borescope clips under `media/`, indexed by `media/index.jsonl` |
| Electrical inspections | `mes-log-mcp/mes/electrical_inspections.py` | What was actually found at one electrical element on one VIN: `{id, vin, element, at, by, condition, note, media_ids}` |
| Service ledger | `mes-log-mcp/mes/service.py` | Oil changes, general service, brakes/wheels/tyres -- the technician's own completed work, distinct from `dealer.py` (wiTECH) and `notes.py` (free-text context) |
| Dealer results | `mes-log-mcp/mes/dealer.py` | wiTECH results typed in by hand -- the only path dealer-tool evidence enters the corpus, since wiTECH has no API |
| Checklists | `cuore/live/checklists.py` | Shop-visible step state for open-work cards (`checklists.json`) |
| Live observations | `cuore/live/store.py` (written) / `mes-log-mcp/mes/live_obs.py` (read) | One JSON line per live adapter read; the evidence gate's only live-data input |
